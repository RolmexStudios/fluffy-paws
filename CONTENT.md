# Content blueprint

`content/blueprint.json` is generated by scanning the template JSX in the main app (`src/app/page.tsx` after export; in the monorepo, `src/components/templates/brochure/template-a/index.tsx`).

If you write `<Hero />` (or `<BrochureHero />`) twice, compile/export creates `BrochureHero_1` and `BrochureHero_2`. Each key starts from that block's `blueprint.json`. Empty images show the instance id so you can match JSON to the screen.

```bash
# After adding/removing brochure section tags in the page template:
npm run blueprint:empty
# or a new export:
npm run export:site -- --template brochure/template-a --name acme-shades
```

Do not hand-edit instance names unless you also change how many times the tag appears.

## Local images (this site only)

Paths like `/assets/0.jpeg` in `blueprint.json` are served from **`public/assets/` inside this project** (e.g. `public/assets/0.jpeg`), not from the monorepo root `public/` folder. Remote `https://` image URLs are copied there by `npm run assets:localize`.

Re-exporting or recreating the site does **not** copy your images. Back up `public/assets/` and `content/blueprint.json` before a full export.
